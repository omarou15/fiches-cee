# Complements CEE essentiels

Ce dossier complete les fiches d'operations standardisees avec les pages CEE importantes referencees depuis la rubrique officielle "Energies" du ministere.

Source :
https://www.ecologie.gouv.fr/politiques-publiques/energies

## Principe de selection

Le but n'est pas de faire un miroir complet des archives du ministere. Les elements retenus sont ceux qui sont utiles pour comprendre ou appliquer le dispositif CEE :

- pages de reference CEE en `page.txt` et `page.html` ;
- documents actifs ou structurants des coups de pouce ;
- documents 2026 pour les lettres d'information, flash infos et statistiques ;
- guides, doctrine, catalogues et formulaires utiles pour les programmes CEE ;
- textes consolides ou recents pour le dispositif general.

Les conventions anciennes, supports d'ateliers historiques, tableaux repetitifs et archives non essentielles ont ete volontairement exclus.
