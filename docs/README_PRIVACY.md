# Confidentialite et donnees privees

Ce depot est public et ne doit contenir aucune donnee client reelle.

Interdit dans le repo public :

- noms de clients reels ;
- adresses de chantiers reels ;
- devis, factures, AH ou signatures reelles ;
- logos d'entreprise reelle ;
- photos de chantier ;
- dossiers EMMY/PNCEE reels ;
- archives ZIP contenant des pieces client.

Dossiers locaux recommandes :

```text
private/
outputs/
clients/
dossiers/
```

Ces dossiers sont ignores par Git. Les PDF officiels des fiches CEE ne sont pas
ignores globalement, car ils font partie de la source reglementaire publique du
toolkit.
